# A.FITAMINE — design changelog

## 0.2.0 — Coach workspace visual pass

**Direction:** premium performance-coaching workspace; graphite surfaces, lime
action accent, restrained color for metrics, clear navigation, and responsive
layouts.

**Included:** sidebar and active-nav refinement, sticky translucent header,
spacing and surface polish, mobile touch-target and spacing adjustments, focus
visibility, reduced-motion support, bright-theme compatibility, and removal of
a duplicated onboarding label. Date defaults/projections now start from today.

**Not changed:** core client records, coaching calculations, training and macro
features, client-switching model, and PDF dossier workflow.

**Review checklist:**
- [ ] Desktop: sidebar and all seven navigation destinations
- [ ] Mobile: menu, client roster scrolling, add-client form, keyboard behavior
- [ ] Dark and bright theme contrast
- [ ] Charts, forms, long client names, and small-screen overflow
- [ ] PDF/print output
